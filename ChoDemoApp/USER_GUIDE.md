# ChronoSync 用户使用指南

## 📱 应用简介

**ChronoSync**（万机）是一款智能日程管理应用，基于 AI 助手帮助您高效管理时间和任务。

### 主要功能
- 📅 **智能日历** - 可视化日程管理，支持工作/生活/学习分类
- 🤖 **AI 助手** - 自然语言创建、查询、修改日程
- 📝 **备忘录** - 快速记录待办事项
- 📷 **智能识别** - 拍照识别文字自动生成备忘录

---

## 🔧 安装配置

### 系统要求
- Android 7.0+ (API 24)
- 网络连接（用于云端同步和 AI 功能）

### 首次使用配置

#### 1. 配置 API Key（必须）
在项目根目录创建 `.env` 文件：
```properties
kimiApiKey=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> **获取方式**：登录 [Kimi 开放平台](https://platform.moonshot.cn/) 获取 API Key

#### 2. 配置后端地址（可选）
如需连接自定义后端，创建 `后端.env`：
```properties
kimiapi=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

默认使用后端：`http://115.190.155.26:8000`

## 📅 日程功能

### 查看日程
- **月视图**：左右滑动切换月份
- **日期标记**：有日程的日期底部显示彩色条
  - 🔵 蓝色 = 工作 (WORK)
  - 🟤 棕色 = 生活 (LIFE)
  - 🟣 紫色 = 学习 (STUDY)
- **详情列表**：点击日期查看当天所有日程

### 创建日程

#### 方式 1：手动创建
1. 选择日期
2. 点击右下角 **+** 按钮
3. 填写信息：
   - 标题
   - 开始/结束时间
   - 类型（工作/生活/学习）
   - 优先级（低/中/高）
4. 点击保存

#### 方式 2：AI 助手创建
1. 切换到"助手"Tab
2. 输入自然语言，例如：
   - "帮我安排明天下午3点的会议"
   - "后天晚上8点健身"
   - "下周三上午10点项目评审"
3. AI 自动创建日程

### 编辑/删除日程
- 点击日程列表中的条目
- 在弹出对话框中修改或删除

### 智能定位生成
- 点击日历页面的 📍 定位按钮
- 获取当前位置
- AI 根据地点和时间智能推荐日程

## 🤖 AI 助手功能

### 支持的指令

| 指令类型 | 示例 | 说明 |
|----------|------|------|
| **创建日程** | "帮我安排明天下午3点的会议" | AI 自动解析时间并创建 |
| **查询日程** | "明天有什么安排" | 查看单日日程 |
| **范围查询** | "最近3天有什么安排" | 查看多日日程 |
| **修改日程** | "把会议改到后天4点" | 修改已有日程 |
| **删除日程** | "删除明天的会议" | 删除指定日程 |
| **创建备忘** | "记住买牛奶" | 创建备忘录 |
| **查询备忘** | "查看我的备忘录" | 列出所有备忘 |

### 时间表达
支持多种自然语言时间：
- **相对时间**：今天、明天、后天、大后天
- **周表达**：本周、下周、周一、周二...
- **具体日期**：3月22日、3月22日下午3点
- **时间段**：这两天、最近3天、未来7天

### 建议确认
当创建日程发生冲突时，AI 会：
1. 提示时间冲突
2. 推荐可用时段
3. 显示 [使用建议时间] [重新输入] 按钮
4. 点击确认即可自动应用

### 对话历史
- 助手页面自动保存对话记录
- 刷新页面后历史保留
- 点击"清空"按钮可清除历史

## 📝 备忘录功能

### 创建备忘
1. 切换到"备忘"Tab
2. 点击"新增"按钮
3. 输入标题和内容
4. 保存

### 拍照识别
1. 点击"拍照"按钮
2. 拍摄照片
3. AI 自动识别文字并生成备忘录
4. 可编辑后保存

### 编辑/删除
- 点击备忘录条目
- 在对话框中修改或删除

### 云端同步
- 登录后自动同步云端数据

## 💡 使用技巧

### 1. 快速创建日程
在助手页面输入：
```
明天下午3点开会
```
AI 自动解析为：
- 日期：明天
- 时间：15:00-16:00
- 标题：开会

### 2. 批量查询
```
本周安排
最近3天的日程
```

### 3. 智能修改
```
把会议推迟一小时
将明天的健身改到晚上8点
```

### 4. 冲突处理
当 AI 提示时间冲突时：
- 点击"使用建议时间"自动调整
- 或点击"重新输入"修改需求

## ⚠️ 常见问题

### Q: AI 助手无法使用？
**A**: 检查是否：
1. 已登录账号
2. `.env` 文件中配置了正确的 `kimiApiKey`
3. 网络连接正常

### Q: 日程没有显示？
**A**: 
1. 确认已登录
2. 点击底部"日程"Tab 刷新
3. 检查网络连接

### Q: 时间显示不对？
**A**: 
应用统一使用北京时间，与设备时区设置无关。

### Q: 如何备份数据？
**A**: 
数据自动同步到云端，更换设备只需登录同一账号即可恢复。
